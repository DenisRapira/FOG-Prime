FOG Prime 2.0

Автоматические профили для Discord и YouTube, быстрый повторный запуск и обновлённый интерфейс. Диагностика работает локально, без обязательного сервера FOG.

Локальная служба готова

Один понятный сценарий

FOG Prime проверяет систему, выбирает ограниченный проверенный профиль соединения и подтверждает доступ. Не нужны аккаунт, подписка, удалённый прокси или телеметрия.

Диагностика соединения

Проверка DNS, настроенных конечных точек, CDN-маршрутов, транспортов реального времени, TLS и QUIC.

Доверенная локальная среда

Аутентификация команд UI → Agent и проверка SHA-256 каждого runtime-файла.

Автовосстановление

Контроль Engine, повторное использование здоровой сессии и восстановление после сбоя.

Три этапа без ручной настройки

Проверка системы

Контроль служб Windows, целостности runtime и базовой готовности сети.

Настройка соединения

Выбор одного из встроенных профилей и запуск нативного Engine.

Проверка доступа

Стабильные health-checks и итоговый статус настроенных конечных точек.
