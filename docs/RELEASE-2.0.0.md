# FOG Prime 2.0.0

Обновление автоматического подключения Discord и YouTube для Windows 10/11 x64.

## Что нового

- Автоматический подбор профилей с возвратом к лучшему найденному варианту.
- Подключённый Discord не отключается только из-за тайм-аута вспомогательного HTTP-запроса.
- Отдельный учёт ошибок голосового соединения и основного Gateway.
- Запоминание проверенного профиля для последующих запусков. Проверки через VPN не сохраняются как подтверждение работы обхода.
- Первая проверка запускается сразу после старта движка, без ожидания фонового таймера.
- Обновлённые целевые правила Discord/YouTube и проверка целостности пакетных образцов.
- Интерфейс без стандартной рамки Windows, анимация соединения, поддержка уменьшенного движения и остановка анимации в фоне.
- Восстановление интерфейса WebView2 и усиленная очистка дочерних процессов.

## Установка

1. Закройте предыдущую версию FOG.
2. Скачайте `FOG-Prime-2.0.0-win-x64.zip` и распакуйте полностью в отдельную папку.
3. Запустите `FOG Prime.exe` и подтвердите запрос Windows.

Нужны Windows 10/11 x64, Microsoft Edge WebView2 Runtime и права администратора.
Не переносите один EXE отдельно от остальных файлов пакета.

## Проверки и ограничения

48 автоматических тестов, проверки интерфейса на трёх размерах окна, проверки
целостности пакета и параметров движка. Проверка Gateway не гарантирует слышимость
голоса, а проверка YouTube не заменяет проверку воспроизведения видео.
Результат зависит от сети и других сетевых программ; совместимость с каждым
античитом не гарантируется. VPN не отключается автоматически.

В релизе приложен SHA-256 архива. Предыдущая версия v0.1.9 сохранена для отката.
Исходники и происхождение сторонних компонентов доступны в репозитории и
`THIRD_PARTY_NOTICES.md` внутри пакета.
