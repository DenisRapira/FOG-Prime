# Project Audit - 2026-11-27

## Decision

The local 2.0.3 candidate is improved and passes the checks below. This is not
a certificate of zero vulnerabilities, clean antivirus results or universal
network compatibility. Public stable remains v2.0.2. Nothing was committed,
pushed, published or deployed during this audit.

Scope: managed application, IPC and lifecycle, packaging, dependency metadata,
repository documentation, bilingual website and patch/release workflows.
Deep review used separate managed-code, documentation and website reviewers.
The native source/driver audit is **incomplete**; existing native parameter
dry runs do not substitute for it. SQL, payment, tenant and cloud-identity
checks do not apply to this local utility.

## Verification Performed

- Release build: **zero warnings, zero errors**.
- Managed console harness: **97/97 passed**, including eight new named
  regression tests containing multiple deterministic topology/ordering cases.
  These are not 97 live-network scenarios.
- Fresh package: **33 files**, exact layout check passed. Original signed
  driver retained; six executable/library/driver hashes match build inventory.
- Package security checks: authenticated IPC/lifecycle and rejection of
  modified Agent, profiles, manifest, native files and game assets passed.
  These tests use temporary copies and do not load the network driver.
- Native command-line checks: four profiles with Game Filter off/on,
  **8/8 `--dry-run` checks passed**; no live Engine was started.
- Mocked embedded UI: seven connection states at 520x740, 460x640 and 680x940;
  dialogs, keyboard focus, manual switch, duplicate rendering, hidden timers,
  reduced motion and overflow checks passed.
- Website: EN/RU at 1366x900 and 390x844 passed local Playwright checks;
  screenshots inspected. Both deployed URLs responded HTTP 200. Deployed
  English metadata was still 2.0.1; local changes are not online.
- NuGet advisory query including transitive managed dependencies returned no
  known advisories on this date. A fail-closed script is now wired into CI.
  This does not audit native binaries or prove absence of unknown defects.
- Locked browser QA dependencies installed with `npm ci --ignore-scripts`.
  All four workflow files parsed as YAML; PowerShell scripts parsed; version
  agreement and mismatched-version/live-test rejection guards passed.
  GitHub-hosted jobs were not executed by this audit.
- Limited secret-pattern and tracked certificate/key filename checks found no
  matching credentials. This is not an exhaustive historical secret scan.
- `git diff --check` passed. Existing dirty work was preserved; the package
  truthfully records a modified working tree rather than claiming a clean tag.

## Remaining Work, in Priority Order

1. **Distribution review:** resolve exact corresponding-source availability for
   native dependencies and permissions for referenced packet/list assets.
   See `LICENSE-COMPLIANCE.md`. Retain third-party attribution; the application
   MIT license does not replace dependency terms. This report is not legal
   clearance.
2. **Real acceptance:** test the exact downloadable artifact on isolated Windows
   systems, without VPN for provider-specific behavior, then with controlled
   VPN transitions. Validate two-way Discord audio, sustained YouTube, games,
   sleep/network change, long sessions and supported anti-cheat coexistence.
   No game restarts or host-network resets were performed here.
3. **Privilege separation:** WebView2/UI still runs elevated. Keep embedded UI,
   navigation and IPC restrictions; design an unelevated UI with a narrow
   privileged broker as a separate architectural change. Actual writable-path
   ACL/loader conditions require isolated testing; no exploit is asserted.
4. **Native audit and provenance:** review the full native source/patches and
   actual loader/driver behavior; record toolchain versions and source tree
   hashes. A CI rebuild and a local prebuilt runtime are not assumed identical.
   Signed-driver trust is not proof of bug-free kernel behavior.
5. **Authenticode/AV:** FOG application executables are unsigned. The original
   driver has a valid separate signature. Defender was stopped and no local
   scan ran. VirusTotal API key was unavailable: **no VT verdict and no file
   uploads**. Never add obfuscation, AV exclusions or false signing claims to
   obtain a cleaner-looking release.
6. **Public information:** apply reviewed About/topics and deploy Pages only
   with approval; see `REPOSITORY-METADATA.md`. Verify confidential GitHub
   vulnerability reporting is enabled. Preserve old stable assets and make
   future metadata track actual publication, not merely tags.
7. **UX follow-up:** distinguish endpoint availability from confirmed voice,
   bound silent waiting with a useful recovery state, keep technical detail
   collapsed, retain one manual game switch and add privacy-safe diagnostics
   export only after a real redaction layer. No UI redesign was made here.
