FOG Prime

Educational connection diagnostics and verified network profiles running entirely on your Windows PC.

Download for Windows x64 View source on GitHub
Local service ready

One focused workflow

FOG Prime checks the system, selects an audited connection profile, and verifies access. No account, subscription, hosted proxy, or telemetry is required.

Connection diagnostics

Checks DNS, configured endpoints, CDN paths, real-time transports, TLS and QUIC availability.

Trusted local runtime

Authenticates UI-to-Agent commands and verifies every packaged runtime file with SHA-256.

Automatic recovery

Supervises the native Engine, reuses healthy sessions and recovers from unexpected exits.

Three steps, no manual profile editing

Check the system

Validate Windows services, runtime integrity and basic network readiness.

Configure the connection

Choose from a constrained set of bundled profiles and start the native Engine.

Verify access

Run stable health probes and report whether the configured endpoints are ready.
