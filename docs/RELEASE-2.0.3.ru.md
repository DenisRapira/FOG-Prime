# FOG Prime 2.0.3

Обновление интерфейса, фоновой работы и восстановления подключения.

## Что изменилось

- Этапы «Система → Подключение → Доступ» показывают реальное состояние,
  без названий профилей и выдуманных процентов.
- Новая CSS-анимация подключения; после успеха появляется галочка и движение
  прекращается. Поддерживается уменьшение анимации в настройках системы.
- При сворачивании WebView2 приостанавливается, Agent продолжает работать.
  После возврата окно получает актуальное состояние.
- Устаревшие проверки отменяются при смене сети. Улучшены порядок запуска и
  остановки, сохранение рабочих профилей и защита от устаревших результатов.
- Снижена частота фоновых проверок в устойчивом состоянии и убраны лишние
  перерисовки. Рабочие настройки запоминаются отдельно для разных сетей.
- Один ручной переключатель игрового фильтра, без списка игр в интерфейсе.
  Внутренний каталог включает ROB RUN и Warframe.
- Основной EXE получил иконку. Agent, Engine и настройки находятся в `app/`:
  в корне больше нет нескольких файлов для запуска.
- Усилены проверка целостности, защита IPC и ограничения запросов обновлений.
- Переход на .NET 10; среда .NET включена в сборку. WebView2 требуется отдельно.

## Установка

Скачайте `FOG-Prime-2.0.3-win-x64.zip`, закройте старый FOG и распакуйте архив
в новую папку. Запускайте только **FOG Prime.exe**. Не переносите EXE отдельно
от папок `app/` и `notices/`. При полном закрытии завершаются процессы FOG.

`FOG-Prime-2.0.3-win-x64.sha256` содержит SHA-256 пользовательского архива.
Архивы Cygwin/WinDivert с `src` или `source` в названии — исходники зависимостей;
для запуска программы они не нужны. Обычному пользователю нужен только ZIP FOG.

## Проверки и ограничения

108/108 автоматических тестов, UI на трёх размерах окна, проверка подмены файлов,
параметров профилей и сворачивания/возврата окна. Пользователь подтвердил работу
на своём ПК; это не проверка всех провайдеров, игр и античитов.

Сетевые правила Discord/YouTube и оригинальный подписанный драйвер сохранены.
EXE приложения не имеет производственной Authenticode-подписи. Антивирусный
вердикт «чисто» не заявляется; файлы в VirusTotal не загружались.
FOG не сбрасывает DNS/сеть, не отключает VPN и не перезапускает игры.
Исправление NAT, серверных лагов и универсальная совместимость не гарантируются.
